# Outreach requests — request-only sources

Request-only sources are outreach, not scraping (standing guardrail): the
roster is confirmed or strongly evidenced to exist but is not public, so Cedar
asks for it directly and never scrapes thin evidence pages as if they were the
roster. Every ask below cites its basis. Nothing here authorizes a scraper;
obtaining a roster converts the source in a registry edit with a verification
log entry, not by improvising coverage.

All outreach is human-performed: sending these requests requires a named Cedar
contact, an explained purpose, and respect for each nation's data governance —
none of which is automatable. This file is the queue, not the sender.

## Protocol notes

- Never request or accept credentialed access on Cedar's behalf without a
  human decision (MySealaska-class portals stay untouched).
- A received roster is a Tribal Primary/Partnership artifact: store it as an
  immutable raw artifact with received-date and provider, and record the
  conversion in verification_log.jsonl.
- If a nation declines or sets terms, record the terms in the registry row's
  caveats and honor them; declining is a valid permanent outcome.
