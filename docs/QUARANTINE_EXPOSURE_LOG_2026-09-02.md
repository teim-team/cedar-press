## 1. What was wrong

`docs/CROSS_DATASET_LEARNING.md` channel 3 quarantines three attribution
methods — `cluster_v3`, `need_v6`, `sam_namematch_2026_05_06`. `need_v6`'s
measured accuracy, in START_HERE's own words, is **6.5%**. `cluster_v3`'s own
`tier_rationale` reads *"Algorithmic name clustering, unreviewed."*

On every prime row those methods keyed, `prime_contracts.attribution_method`
read `uei_exact`, `cage_exact` or `parent_uei`.

**That column was not lying. It was answering a different question.** It
records HOW THE IDENTIFIER JOINED — we matched a UEI to a UEI, which is exact —
and says nothing about HOW THE IDENTIFIER WAS RULED. A quarantined guess and an
owner ruling were byte-identical to every consumer. This is START_HERE trap 1
in a third vocabulary: *the exactness of the KEY says nothing about the
correctness of the LINK.*

**`TRBF-TEMOAK-00` is Te-Moak, whose spine `aliases` field contains a PROSE
SENTENCE** — *"Four constituent bands: Battle Mountain Band; Elko Band; South
Fork Band; and Wells Band"*. It collected `Four Tribes Enterprises`, `Four Bears
Construction`, `Four Directions Media`, `Four Corners Clean`, `Four Seasons
Construction`, `Eighty-Four Packing Co`, `Battle Creek Construction`, `E W Wells

**`AKNF-VEAGLE-00-DOYONL-TNNACH` is the Native Village of Eagle.** Its entire
distinctive token set is `{eagle}` — one word, already on

whose entire distinctive token set is generic may not win a match that rests

over `cluster_v3`'s output. **This pass applies it backwards.**

**Three guards, every one earned on a false positive found while building it:**

1. **≥2 distinctive tokens.** Killed `REGIONAL SERVICES LTD` → Bering Straits
   and `INFORMATION TECHNOLOGY SOLUTIONS CORP` → Koniag, where the "hit" was an
   English phrase.
2. **A NAMING is not an OWNING.** The ±200-character window must read like a
   subsidiary *list* (≥3 corporate-form tokens) or carry an ownership verb
   (`subsidiary`, `acquired`, `wholly owned`, `interest in`, `was formed`,
   `owns`). Killed `KING ISLAND NATIVE CORPORATION` → Bering Straits (a
   shareholder greeting) and `BRISTOL BAY NATIVE ASSOCIATION` → BBNC (a photo
   caption reading *"funded by the bristol bay housing authority bristol bay
   native association and bbnc"*).
3. **An explicit VETO on `third party`, checked across EVERY occurrence.**
   Bering Straits names `tanana commercial company` twice: once in an
   equity-investment table and once as *"a joint venture operation between emi
   and **a third party** tanana commercial company"*. Reading only the first
   occurrence read the wrong one.

Plus two structural guards: a firm that **is itself a Cedar entity** and a firm
carrying an **institution-form word** (`authority`, `association`, `commission`,
`school`, `housing`, …, rule 7's HOLD row) are never repointed on a report
mention.

### 4b. `cross_dataset_propagation` is NOT accepted as corroboration

It has already carried `cluster_v3`'s guesses onto CAGE codes at these very
hubs — `Blue Steel Company` at Blue Lake, `Eagle Butte Cooperative Assn` at the
Native Village of Eagle, `Government & Industrial Supply` at Barrow. Counting
it would let the defect corroborate itself: the evidence-lineage trap
`docs/ASSERTION_LAYER.md` names, where two sources agreeing are one source
twice. Only ruled and two-leg methods count as siblings.

### 4c. THE FRAGMENT RULE — the new one this pass earns

Where the hub's name carries **two or more** distinctive tokens and the firm
matched exactly **one** of them, the firm did not match the NAME. It matched a
FRAGMENT of one. `ENTITY_MATCH_RULES` opens on this exact defect — *"104
`alias_type='brand'` rows, every one a single token — `cultural`, `indigenous`,
`colorado`, `broadband`, `advantage`; the alias was a fragment of a company
name, not a name"* — and never applied it to `cluster_v3`. Applied here, after
all seven rungs have failed, it accounts for **$5.53B**:

## 7. Rules this pass earns

1. **A column that records the JOIN while hiding the RULING is a defect**, not
   a convenience. The ledger's method and tier now travel with the transaction.
2. **A prose sentence in an alias field is not a name.** Te-Moak's alias field
   held one, and it cost $831M.
3. **The FRAGMENT rule** (§4c) — one token of a multi-token hub name is not a
   name match, after every corroborator has failed.
4. **A joint venture is never withdrawn on a name test.** It has two parents.
5. **A NAMING is not an OWNING** (§4a guard 2), and **any** occurrence calling
   a firm *"a third party"* vetoes every occurrence.
6. **A method that has already laundered a quarantined method's output cannot
   corroborate it** (§4b).
7. **`os.replace` cannot rename a file the same process still holds open.** The
   rename lost to WinError 5 three times and the first diagnosis — *a
   concurrent agent has it open* — was wrong, and plausibly wrong, because
   twelve other agent processes really were live. The generator now owns the
   read handle and closes it before the rename. **Look for your own handle
   before you blame the neighbours.**
8. **A gate must not read a number a previous run of the same script wrote.**
   `verify` used to compare against a stored proof, and a `report` run
   overwriting that file with a report-mode payload turned the gate into a
   no-op that exited 0. It now re-derives both sides from the `.bak_<TAG>`
   pre-state and the live table, and writes the proof as an *output*.
9. **Three checks in this one pass measured something other than their own
   name** — a `mode()` with no tie-break that made the classifier
   irreproducible; an over-broad leg test that reported 8,352 phantom breaches;
   and a determinism test that compared a pre-state run against a post-state
   run and called the difference nondeterminism. That is `AGENT_FIELD_GUIDE`
   section 3 three times in one day, in one script, by one agent. **Print the
   denominator and one worked example row** would have caught all three.

## 8. Re-running

```
py -3 code/1079_quarantine_method_exposure.py report    # measure only, writes review/ + the .report.json
py -3 code/1079_quarantine_method_exposure.py apply     # measure + repair, idempotent and resumable
```

`apply` is **idempotent and resumable** on one rule: *a file whose
`.bak_<TAG>` exists has already been processed by this pass*, and the pre-state
inputs — the ledger and the prime aggregates — are read from that backup, never
from the live table. A half-finished run can simply be re-run.
