# Gaming Grove data contract

Generated by `py -3 code/build.py grove-contracts gaming` from each registered producer's `CONTRACTS` and the shared vocabularies in `code/gaming_grove.py`. Do not edit; `--check` fails when this file is stale.

Collection `gaming` is a **Cedar Grove** collection, not a Cedar Press storefront collection. Schema `cedar.grove.gaming.v1`. Identifier contract status: `PENDING_CICD_RETIREMENT_AUDIT`; while it is not `APPROVED`, every component ID is rendered `PROV-...`, candidates are `LOCAL_DRY_RUN_PROVISIONAL_IDS`, and `release-pilot` refuses them.

Build: `py -3 code/build.py candidate gaming --input-root <Cedar data root> --output-root <new root outside Git> --as-of <YYYY-MM-DD> [--previous <prior candidate root>]`. Release (one approved flagship): `code/build.py release-pilot gaming`.

## Field rights classes

- `public_official` (public): Official government/tribal publication; attributed, publishable after transformation review
- `public_derived` (public): Computed only from public_official fields by a documented method
- `internal_vendor` (never public): Commercial directory / Casino City Press / trade-directory lineage; internal QA only
- `internal_model` (never public): Modeled, estimated, IMPLAN or research-inferred value; internal QA only
- `internal_crosswalk` (never public): Identifier kept for reconciliation, never a public key
- `withheld_unverified` (never public): No independent publishable evidence yet; withheld
- `withheld_suppressed` (never public): Source-suppressed or confidentiality-limited; withheld

## Derived identifier prefixes

- `GREV`: regional/national revenue observation
- `GBND`: revenue-band observation
- `GFNM`: facility name/alias period
- `GFST`: facility status period or history event
- `GFCP`: facility capacity/amenity observation
- `GREL`: facility-entity-enterprise relationship
- `GPAY`: government payment / revenue-sharing observation
- `GLIC`: license or regulatory authorization
- `GREG`: regulatory event
- `GENV`: environmental review
- `GLAB`: labor or employment observation
- `GFIN`: financial disclosure
- `GLIT`: litigation or administrative proceeding
- `GADV`: advocacy/lobbying link (points at the Advocacy collection's own ID)
- `GSRC`: source observation / source registry record
